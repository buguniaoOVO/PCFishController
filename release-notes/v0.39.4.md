# PCFish 助手 v0.39.4

## 修复

- **合成 / 繁育成功后的结果面板关不掉，把输入锁死**。面板（「发现新鱼！」）会挡住所有后续动作，界面在「游戏输入被提示窗口阻塞」和「正在等待稳定」之间反复跳，自动化整轮停摆。根因是关闭逻辑用了错误的程序集去取 `UIFishResult` 类，`Confirm()` 从来没真正执行过，面板一直挂在屏幕上。
- **通用提示框的关闭调用同样打空**：`UIAlterMessage` 的真实命名空间是 `NN.PF.UI.Alter`，代码里查的是 `NN.PF.UI.Common`，`Hide()` 从未生效。
- **会话稳定判定被瞬时的 `isBlockUi` 抖动反复清零**：按钮音效、面板动画都会短暂置位输入锁，而判定要求连续 30 秒，于是永远「正在等待稳定」。现在输入锁必须持续 2.5 秒才算真阻塞，稳定期缩短到 5 秒。

## 优化

- 结果面板改为常驻巡检：不再依赖动作结束后几秒的清理窗口（面板是回包之后才弹出的，那个窗口抓不住它）。
- 三重兜底依次尝试——结果面板 `Confirm` → `UIConfirm.Ok` → `UIAlterMessage.Hide`；三条全部打空时清除 `AudioManager.isBlockUi` 这个残留输入锁（它本该由游戏协程自动复原，协程被打断就会永久为 true）。
- `closeResultUi` 内部吞掉异常，避免 UI 反射失败把一次成功的合成 / 繁育误判为失败。

## 说明

- 本次只改内存代理层（`pcfish-agent.js`），连接方式、合成与繁育规则、报价导出的行为都没有变化。
- 升级后请**完全退出游戏再重开**：代理脚本在游戏进程内加载，只重启助手仍会跑旧脚本。
