# PCFish 助手 v0.39.3

## 新功能

- **Frida 内存连接**：按 PID 附加 PCFish，在进程内加载代理脚本，不向游戏目录部署插件。
- 连接方式可在设置页选择自动 / Frida / 插件桥接；自动模式优先 Frida，附加失败会回退插件。
- **赛季配方合成**：材料凑齐（核心鱼×1 + 辅助鱼×3×3 = 10 条）即发起合成，不看仓库阈值；按目标品质降序、神话鱼优先，S1/S2 配方都会尝试。
- **自动报价 / 导出**：按 Steam 近期成交价区间批量把鱼送入 Steam Inventory，支持批次大小、赛季鱼、配方鱼与鱼种多选排除；默认关闭。
- 自动合成可设置人民币成交价保护金额，默认 ¥1；同稀有度、同星级成组挑选，支持高/低稀有度、高/低星级优先。
- 市场报价支持定时查询与本地缓存；扫描成功后替换旧缓存，失败时保留旧缓存。
- 鱼种弹窗显示图标、价格、库存数量、品质和星级；随助手分发 648 个从游戏 AtlasFish 解码重排的图标精灵。
- 新增游戏 10/30 FPS 设置、多开 PID 选择与 Sandboxie 启动入口。
- S2 三种赛季鱼及其 1–5 星配方从游戏 `fish_type_v1.5` 与 `fish_season_recipe_v1.1` 核对。

## 修复

- **会话判定依赖恒为空的 `accessToken` 字段**，导致助手一直停在「等待助手确认游戏会话」、一个动作都不发。改为读不到 token 时降级放行。
- **提示窗口造成 `networkReady` 死锁**：弹窗阻塞输入 → 判定不 ready → 又因为要求 ready 才去关弹窗，形成循环。改为动作结束即开清理窗口。
- **主线程钩子挂载失败后不再重试**，表现为启动后偶发「游戏主线程暂未就绪」、鱼群读不到。改为每 2 秒重试。
- **`_roundActive` 互斥把 Steam 导出永久挡掉**（自动轮次开启时它几乎恒为 true），日志表现为「Steam 导出未发送」。
- 修复插件模式把 UI 管理器的 `isProcessing` 当作忙碌依据导致的频繁暂停。
- 修复 Steam 市场翻页出现重复页时整轮扫描失败，自动合成不再长期卡在等待市场价。

## 说明

- 自动合成的分组规则是「同品质 + 同星级 ≥ 10 条」，因此神话鱼数量不足时不会参与合成，只能靠赛季配方产出。
- 繁育产出与亲鱼同品质的随机品种，星级取亲鱼较高者。
- 真实 Steam 导出未执行过，界面会要求确认。
