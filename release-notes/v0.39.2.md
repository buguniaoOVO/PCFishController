# PCFish 助手 v0.39.2

- 新增 Frida 内存连接：按 PID 附加 PCFish，在进程内加载代理脚本，不向游戏目录部署插件。
- 连接方式可在设置页选择自动 / Frida / 插件桥接；自动模式优先 Frida，附加失败会回退插件。
- Frida 模式实测可读取完整鱼群、繁育计数器、鱼缸等级和经验，并执行隐藏合成与原生繁育。
- 合成与繁育回执来自游戏自身对象变化：核对鱼群增减、亲鱼次数和新鱼 ID。
- 游戏弹出通用提示框时自动点「确定」，避免输入锁挡住后续动作。
- 修复插件模式把 UI 管理器的 isProcessing 当作忙碌依据导致的频繁暂停。
- 修复 Steam 市场翻页偶尔出现重复页时整轮扫描失败，自动合成不再长期卡在等待市场价。
- 自动合成可设置人民币成交价保护金额，默认 ¥1；同稀有度、同星级成组挑选，并支持高/低稀有度优先。
- 合成和繁育优先级增加高/低星级选项。
- 自动合成页按当前 S1/S2 赛季显示排除项，并可分别排除 S1/S2 配方材料；鱼种弹窗显示图标、价格、库存数量、品质和星级。
- 新增游戏 10/30 FPS 设置、多开 PID 选择与 Sandboxie 启动入口；控制器一次连接一个游戏进程。
- S2 三种赛季鱼及其 1–5 星配方从当前游戏 `fish_type_v1.5` 和 `fish_season_recipe_v1.1` 核对，并显示 S1/S2 筛选路线。
- 随助手分发从游戏 AtlasFish 解码并重新排版的 648 个图标精灵，运行时用库存 `sp` 编号匹配。
- 市场报价支持定时查询和本地缓存；新报价扫描成功后替换旧缓存，失败时保留旧缓存。
- 自动 Steam 导出支持价格范围、批次、赛季鱼、配方鱼和鱼种多选排除；默认关闭，启用需确认。真实 Steam 导出未执行。
- Frida Worker 退出时先执行 prepareDetach、卸载脚本并断开会话；若提示持续阻塞输入，尝试调用游戏自己的 UIAlterMessage.Hide()。

## 修复与增强（2026-10-29）

- 修复：会话判定依赖恒为空的 `accessToken` 字段，导致助手一直停在「等待助手确认游戏会话」、一个动作都不发。改为读不到 token 时降级放行。
- 修复：提示窗口会阻塞输入并让 `networkReady` 恒为 false，而清理弹窗又要求 `networkReady`，形成死锁、界面卡在「等待游戏会话」。改为动作结束即开清理窗口。
- 修复：主线程钩子挂载失败后不再重试，表现为启动后偶发「游戏主线程暂未就绪」。改为每 2 秒重试。
- 修复：`_roundActive` 互斥把 Steam 导出永久挡掉（自动轮次开启时它几乎恒为 true），日志表现为「Steam 导出未发送」。
- 新增：赛季鱼材料凑齐即合成、无视仓库阈值。按目标品质降序、神话鱼优先，S1/S2 配方都会尝试。
- 新增：`GameApiClient`，游戏 HTTP 协议直发的骨架（当前未启用，控制器默认走游戏内动作路径）。
